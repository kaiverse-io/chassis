# Papercuts

Friction an agent hit while working here: a command that needed a retry, a doc or skill step that
was wrong, a gotcha. Append an entry; `/dev-coach` groups them, turns repeats into a rule, a skill
fix or a check, and removes the entries it has acted on. This directory is public if the repo is,
so describe the project, never the operator.
